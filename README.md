# ONE PLAY

Premium social gaming platform. Turkish-first, mobile-first web experience.

## Stack
- Next.js 15 / React 19 / TypeScript
- Supabase (planned: auth, database, realtime)
- LiveKit (planned: voice rooms)
- Vercel deployment

## Local development
1. Install Node.js 20.9+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and fill service credentials.
4. Run `npm run dev`.

## Current status
Phase 1 UI foundation: responsive discovery page, room discovery preview, game catalogue preview and navigation interactions.
Authentication, persistent data, voice and multiplayer are not enabled yet. Do not enter real payment details or treat demo room counts as live data.
